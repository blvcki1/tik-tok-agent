📖 Guide Rapide : Connecter Gemini IA & TikTok
Comment activer le plein potentiel de ton Agent en quelques minutes
1. Clé Google Gemini API (Gratuite)

• Rendez-vous sur aistudio.google.com/app/apikey.
• Cliquez sur Create API Key.
• Collez-la ci-contre : l'Agent utilisera Gemini 2.5 Flash Vision pour inspecter vos vraies photos/vidéos et rédiger des posts sur mesure.

2. API Officielle TikTok Content Posting

• Créez une application gratuite sur developers.tiktok.com.
• Activez les produits Login Kit et Content Posting API (scopes : user.info.basic, video.publish, video.upload).
• Ajoutez l'URL de redirection (Callback) : http://localhost:3005/api/tiktok/callback.
• Collez votre Client Key et Client Secret à droite puis cliquez sur Connecter mon compte TikTok.
